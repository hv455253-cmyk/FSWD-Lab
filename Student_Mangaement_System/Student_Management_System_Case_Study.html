PART A. Comprehensive Question

Case Study: Student Management System

An educational institution maintains student enrollment, academic performance, and personal contact details in separate spreadsheets and registers. Academic departments face challenges tracking active student strength, updating semester GPAs, preventing duplicate enrollments, and generating department-wise academic statistics. The institution requires a web-based Student Management System that stores student records in a managed cloud database and can be accessed securely over the internet.

Design and develop a database-driven Student Management System using React, Node.js, Express.js, and MongoDB. Deploy the frontend and backend on suitable cloud platforms (Vercel and Render) and make the application accessible through a web address.

The application must support the following requirements:

  • Store student details such as roll number, full name, email, department, academic year, GPA, and enrollment status.
  • Create and manage a MongoDB database (student_db) and students collection using an appropriate document structure.
  • Perform CRUD operations: add a student, display students, modify student details, and delete a student record.
  • Write MongoDB queries to insert, retrieve, update, and delete documents.
  • Use aggregation to generate department-wise student counts, average GPA, and highest GPA summaries.
  • Create indexes to support unique roll number lookup and efficient department-based queries.
  • Deploy the backend (Render), frontend (Vercel), and database (MongoDB Atlas) using cloud platforms. Explain the role of hosting, domain names, and environment variables.
  • Test the deployed application and confirm that data entered through the interface is stored in MongoDB and can be retrieved.

PART B. Worked Solution

1. Analyse the requirements

Requirement Solution
Student identity A unique roll number (rollNumber) identifies each student.
Student details name, email, department, year, gpa, and enrollmentStatus are stored in each document.
Data storage MongoDB database: student_db; collection: students.
Application operations React sends HTTP requests to Express API routes; Express reads/writes MongoDB documents.
Reports & Analytics Aggregation calculates total students, average GPA, and highest GPA department-wise.
Performance Unique index on rollNumber; secondary index on department.
Deployment MongoDB Atlas hosts the database; Render hosts the backend API; Vercel hosts the React frontend.

2. Design the MongoDB document

A student is represented as one BSON document in the students collection. A possible document is:

{
  "rollNumber": "21CS101",
  "name": "Alex Johnson",
  "email": "alex.j@college.edu",
  "department": "Computer Science",
  "year": 3,
  "gpa": 8.75,
  "enrollmentStatus": "Active"
}

Field design:

Field Suggested data type Purpose
rollNumber String Unique student academic registration code.
name String Full legal name of the student.
email String Unique institutional contact email.
department String Academic department (e.g. Computer Science, Electronics, Mechanical).
year Number Current year of study (1 to 4).
gpa Number Cumulative Grade Point Average (0.0 to 10.0).
enrollmentStatus String Status of student (Active, Graduated, Suspended).

The MongoDB document also receives an automatically generated _id field. The application uses this identifier when editing or deleting a student.

3. Create the database and collection

In MongoDB Shell (mongosh), execute the following commands. A database is persisted when data is stored in it; creating a collection makes the intended structure explicit: 

use student_db
db.createCollection("students")

4. Perform MongoDB CRUD operations

Operation MongoDB query Purpose
Create db.students.insertOne({ rollNumber: "21CS102", name: "Rohan Varma", email: "rohan.v@college.edu", department: "Computer Science", year: 1, gpa: 8.40, enrollmentStatus: "Active" }) Adds a student document.
Read db.students.find({ department: "Computer Science" }) Retrieves students in the Computer Science department.
Update db.students.updateOne({ rollNumber: "21CS101" }, { $set: { gpa: 9.05, year: 4 } }) Modifies the GPA and year of study.
Delete db.students.deleteOne({ rollNumber: "21ME305" }) Removes the matching student document.

Useful additional queries:

// Display all students
db.students.find({})

// Find students with GPA greater than or equal to 8.5
db.students.find({ gpa: { $gte: 8.5 } })

// Sort students by GPA, highest first
db.students.find({}).sort({ gpa: -1 })

// Count total students enrolled
db.students.countDocuments({})

5. Create indexes

An index helps MongoDB locate documents without scanning every document in the collection ($COLLSCAN$). Create a unique index for the roll number and a secondary index for department-based searches: 

db.students.createIndex({ rollNumber: 1 }, { unique: true })
db.students.createIndex({ department: 1 })

// View indexes
db.students.getIndexes()

The unique rollNumber index prevents duplicate student records. The department index supports queries and aggregations that filter students by branch. Indexes consume storage and should be selected according to the queries the application actually performs.

6. Use aggregation for department-wise student summary

The administration requires department-wise analytics: student enrollment strength, average GPA, and highest GPA per department. 

db.students.aggregate([
  {
    $group: {
      _id: "$department",
      totalStudents: { $sum: 1 },
      averageGpa: { $avg: "$gpa" },
      highestGpa: { $max: "$gpa" }
    }
  },
  {
    $project: {
      department: "$_id",
      totalStudents: 1,
      averageGpa: { $round: ["$averageGpa", 2] },
      highestGpa: 1,
      _id: 0
    }
  },
  { $sort: { totalStudents: -1 } }
])

For the sample records, the expected department summary is:

Department Total Students Average GPA Highest GPA
Computer Science 2 8.58 8.75
Electronics 1 9.10 9.10
Mechanical 1 7.80 7.80

Create a folder named backend. Initialise the Node.js project and install the required packages:

Create backend/server.js:

require("dotenv").config();
const express = require("express");
const mongoose = require("mongoose");
const cors = require("cors");
const app = express();

app.use(express.json());

const allowedOrigins = (process.env.FRONTEND_ORIGIN || "http://localhost:5173")
  .split(",").map((origin) => origin.trim());
app.use(cors({ origin: allowedOrigins }));

const studentSchema = new mongoose.Schema({
  rollNumber: { type: String, required: true, unique: true, trim: true, uppercase: true },
  name: { type: String, required: true, trim: true },
  email: { type: String, required: true, unique: true, trim: true, lowercase: true },
  department: { type: String, required: true, trim: true },
  year: { type: Number, required: true, min: 1, max: 4 },
  gpa: { type: Number, required: true, min: 0, max: 10 },
  enrollmentStatus: { type: String, default: "Active" }
}, { timestamps: true });

studentSchema.index({ department: 1 });
const Student = mongoose.model("Student", studentSchema);

app.get("/api/health", (req, res) => {
  res.json({ status: "ok", message: "Student Management API is running" });
});

app.get("/api/students", async (req, res) => {
  try {
    const students = await Student.find().sort({ rollNumber: 1 });
    res.json(students);
  } catch (err) {
    res.status(500).json({ message: "Unable to retrieve students" });
  }
});

app.post("/api/students", async (req, res) => {
  try {
    const student = await Student.create(req.body);
    res.status(201).json(student);
  } catch (err) {
    res.status(400).json({ message: err.message });
  }
});

app.put("/api/students/:id", async (req, res) => {
  try {
    const student = await Student.findByIdAndUpdate(
      req.params.id, req.body, { new: true, runValidators: true }
    );
    if (!student) return res.status(404).json({ message: "Student not found" });
    res.json(student);
  } catch (err) {
    res.status(400).json({ message: err.message });
  }
});

app.delete("/api/students/:id", async (req, res) => {
  try {
    const student = await Student.findByIdAndDelete(req.params.id);
    if (!student) return res.status(404).json({ message: "Student not found" });
    res.json({ message: "Student deleted successfully" });
  } catch (err) {
    res.status(400).json({ message: err.message });
  }
});

app.get("/api/reports/department-summary", async (req, res) => {
  try {
    const summary = await Student.aggregate([
      { $group: {
        _id: "$department",
        totalStudents: { $sum: 1 },
        averageGpa: { $avg: "$gpa" },
        highestGpa: { $max: "$gpa" }
      }},
      { $project: {
        department: "$_id",
        totalStudents: 1,
        averageGpa: { $round: ["$averageGpa", 2] },
        highestGpa: 1,
        _id: 0
      }},
      { $sort: { totalStudents: -1 } }
    ]);
    res.json(summary);
  } catch (err) {
    res.status(500).json({ message: "Unable to generate summary" });
  }
});

const PORT = process.env.PORT || 5000;
async function start() {
  try {
    await mongoose.connect(process.env.MONGODB_URI, {
      dbName: process.env.DB_NAME || "student_db"
    });
    app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
  } catch (err) {
    console.error("Database connection failed:", err.message);
    process.exit(1);
  }
}
start();

8. Develop the React frontend

Create a Vite React application in a separate frontend folder:

npm create vite@latest frontend -- --template react
cd frontend
npm install
npm run dev

Set the API base URL in frontend/.env:

VITE_API_URL=http://localhost:5000

Create frontend/src/App.jsx:

import { useEffect, useState } from "react";
import "./style.css";

const API = (import.meta.env.VITE_API_URL || "http://localhost:5000")
  .replace(/\/$/, "") + "/api";

const emptyForm = { rollNumber: "", name: "", email: "", department: "Computer Science", year: 1, gpa: "", enrollmentStatus: "Active" };

export default function App() {
  const [students, setStudents] = useState([]);
  const [form, setForm] = useState(emptyForm);
  const [editingId, setEditingId] = useState(null);
  const [message, setMessage] = useState("");

  async function loadStudents() {
    const response = await fetch(`${API}/students`);
    if (!response.ok) throw new Error("Could not load students");
    setStudents(await response.json());
  }

  useEffect(() => {
    loadStudents().catch((err) => setMessage(err.message));
  }, []);

  function handleChange(event) {
    setForm({ ...form, [event.target.name]: event.target.value });
  }

  async function handleSubmit(event) {
    event.preventDefault();
    const payload = { ...form, year: Number(form.year), gpa: Number(form.gpa) };
    const url = editingId ? `${API}/students/${editingId}` : `${API}/students`;
    const response = await fetch(url, {
      method: editingId ? "PUT" : "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload)
    });
    const result = await response.json();
    if (!response.ok) { setMessage(result.message || "Save failed"); return; }
    setMessage(editingId ? "Student updated" : "Student added");
    setForm(emptyForm); setEditingId(null);
    await loadStudents();
  }

  function startEdit(student) {
    setEditingId(student._id);
    setForm({
      rollNumber: student.rollNumber, name: student.name, email: student.email,
      department: student.department, year: student.year, gpa: String(student.gpa),
      enrollmentStatus: student.enrollmentStatus
    });
  }

  async function removeStudent(id) {
    if (!window.confirm("Delete this student record?")) return;
    const response = await fetch(`${API}/students/${id}`, { method: "DELETE" });
    const result = await response.json();
    if (!response.ok) { setMessage(result.message || "Delete failed"); return; }
    setMessage("Student deleted"); await loadStudents();
  }

  return (
    <main className="container">
      <h1>Student Management System</h1>
      <p>Manage student records and academic performance.</p>
      {message && <p role="status">{message}</p>}
      <form onSubmit={handleSubmit}>
        <label>ROLL NUMBER<input name="rollNumber" value={form.rollNumber} onChange={handleChange} disabled={Boolean(editingId)} required /></label>
        <label>FULL NAME<input name="name" value={form.name} onChange={handleChange} required /></label>
        <label>EMAIL<input type="email" name="email" value={form.email} onChange={handleChange} required /></label>
        <label>DEPARTMENT<input name="department" value={form.department} onChange={handleChange} required /></label>
        <label>YEAR<input type="number" name="year" min="1" max="4" value={form.year} onChange={handleChange} required /></label>
        <label>GPA<input type="number" step="0.01" min="0" max="10" name="gpa" value={form.gpa} onChange={handleChange} required /></label>
        <button type="submit">{editingId ? "Update Student" : "Add Student"}</button>
        {editingId && <button type="button" onClick={() => { setEditingId(null); setForm(emptyForm); }}>Cancel Edit</button>}
      </form>
      <h2>Student Records</h2>
      <table>
        <thead><tr><th>Roll No</th><th>Name</th><th>Email</th><th>Department</th><th>Year</th><th>GPA</th><th>Actions</th></tr></thead>
        <tbody>{students.map((s) => <tr key={s._id}>
          <td>{s.rollNumber}</td><td>{s.name}</td><td>{s.email}</td><td>{s.department}</td><td>{s.year}</td><td>{s.gpa}</td>
          <td><button onClick={() => startEdit(s)}>Edit</button><button onClick={() => removeStudent(s._id)}>Delete</button></td>
        </tr>)}</tbody>
      </table>
    </main>
  );
}

10. Deploy the application using cloud platforms

Deployment architecture:

Layer Platform Responsibility
Frontend Vercel Hosts the built React application and provides a public frontend URL.
Backend Render Runs the Node.js/Express API and provides a public API URL.
Database MongoDB Atlas Hosts the cloud MongoDB database cluster and stores student documents.

Deployment steps:

  1. Create a MongoDB Atlas cluster. Create a database user, configure network access (0.0.0.0/0), and copy connection string.
  2. Push backend and frontend source folders to a Git repository. Do not commit .env files.
  3. On Render, create a Web Service from the backend repository. Set build command to npm install and start command to node server.js.
  4. Add backend environment variables in Render: MONGODB_URI, DB_NAME=student_db, and FRONTEND_ORIGIN=<your Vercel frontend URL>.
  5. Deploy backend and test its /api/health endpoint. Copy public backend URL.
  6. On Vercel, import frontend project. Set VITE_API_URL to public Render backend base URL, then deploy.
  7. Update FRONTEND_ORIGIN in Render with deployed Vercel URL and restart service. Test all CRUD operations.

Environment variable summary:

Variable Where to set it Example/value
MONGODB_URI Render backend service MongoDB Atlas connection string (secret).
DB_NAME Render backend service student_db
FRONTEND_ORIGIN Render backend service https://your-student-app.vercel.app
VITE_API_URL Vercel frontend project https://your-student-api.onrender.com
Security and deployment caution: Do not place MONGODB_URI in a Vite variable or frontend source code. Frontend variables are visible to users after build. Do not commit credentials. Avoid opening a production database without authentication.
